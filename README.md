## 🚀 Flagship Project — RetailPulse

**AI-powered customer analytics & demand forecasting platform**, built during the Zidio Development internship. Full pipeline from synthetic data generation through validation, segmentation, forecasting, churn prediction, inventory optimization, and drift monitoring — served through a Streamlit dashboard.

| Metric | Target | Result |
|---|---|---|
| Demand forecast MAPE (60-day hold-out) | ≤ 12% | **11.76%** |
| Churn prediction AUC-ROC | ≥ 0.88 | **0.95** |
| Data validation checks passed | — | **17 / 17** |
| Drift detection (features stable) | — | **6 / 6** |

What makes it stand out: the README documents every tooling substitution honestly (e.g. XGBoost → GradientBoostingClassifier when the original wheel wouldn't install), and there's a dedicated `experiments/` folder showing a deliberately leaky first churn model (AUC 1.00 — a red flag, not a win) alongside the fixed version. Shows the debugging process, not just the polished result.

`Python` · `scikit-learn` · `pandas` · `Streamlit` · `Docker` · `GitHub Actions CI`
